## Homedeck Edge 0.9.3 – first release

**🇬🇧** Your Home Assistant on the CORSAIR XENEON EDGE: your own entities as live tiles. Lamps light their tile in their real colour, heating glows orange, sensors show their units. Tap to switch, long-press to dim lights, set the heating, move covers or change the volume.

**🇩🇪** Dein Home Assistant auf der CORSAIR XENEON EDGE: deine eigenen Entitäten als Live-Kacheln. Lampen leuchten in ihrer echten Farbe, Heizungen glühen orange, Sensoren zeigen ihre Einheit. Antippen schaltet, langes Drücken dimmt Lampen, stellt die Heizung ein, fährt Rollos oder ändert die Lautstärke.

### Install / Installieren
1. Download `Homedeck-0.9.3.icuewidget` – herunterladen.
2. Double-click it, iCUE imports the widget – Doppelklick, iCUE importiert das Widget.
3. Create a long-lived access token in Home Assistant (profile → Security) – in Home Assistant ein langlebiges Zugriffstoken erstellen (Profil → Sicherheit).
4. Add **Homedeck** to your XENEON EDGE and enter address, token and entity IDs – **Homedeck** auf die XENEON EDGE ziehen und Adresse, Token und Entitäts-IDs eintragen.

Guide / Anleitung: [README](https://github.com/KaelanTesseract/homedeck-edge#readme)

Requires Windows, iCUE 5.52+, a XENEON EDGE and Home Assistant. Talks only to your own Home Assistant server. Checksums: `SHA256SUMS.txt`.
